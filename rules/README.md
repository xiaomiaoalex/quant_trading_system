# 仓库规则索引

共享入口是 `../AGENTS.md`，`../CLAUDE.md` 与 `../.traerules` 定向引用它。目录名称不代表 Codex 自动加载机制；由入口按任务选择资料。

| 文件 | 何时读取 |
| --- | --- |
| L0_COLLABORATION.md | 旧链接兼容入口 |
| L1_TECH_STACK.md | Python 实现与工程检查 |
| L2_BUSINESS.md | 交易核心、适配、持久化或风控变更 |
| L3_WORKFLOW.md | 跨模块、多阶段任务或明确工作流请求 |

每条约束只维护一处。新增规则需要解决具体反复出现的问题；通用教程、过期进度、示例配额和重复审批不进入常驻指令。
